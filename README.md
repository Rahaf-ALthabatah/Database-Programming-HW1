ACID Properties
- Atomicity:All steps in a transaction succeed together or fail together so partial updates do not stay in the database.
- Consistency: Data stays valid and follows all tables, keys, and constraints before and after a transaction.
- Isolation: Concurrent transactions run without interfering with each other or seeing uncommitted data.
- Durability: Once a transaction is committed, its changes remain saved even after a crash or power loss.
